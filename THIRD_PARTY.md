The data it is built from has its own terms.

| [`deunicode`](https://crates.io/crates/deunicode) | the transliteration table (chunk inventory) | BSD-3-Clause | Copyright (c) 2015 Amit Chowdhury, 2018–2021 Kornel Lesinski, 2020–2021 Hunter WB. Its README lists its data sources: Text::Unidecode by Sean M. Burke, Unicodey by Cal Henderson, gh-emoji and any_ascii. |

`deunicode`'s table is a descendant of Text::Unidecode's, the same ancestor as Python's
`unidecode`. We rely on the crate's declared BSD-3-Clause license, and compare against Python
`unidecode` (GPL-2.0+) only in development (`mise run //tools:translit-unidecode`). Its output never
goes into `data/generated/phono.bin`. The builder reads that table only if you pass `--translit`
by hand.

`crates/builder/src/translit.rs` holds our own overrides to the table (`OVERRIDES`). Each one has to
come from observed TTS behaviour or Unicode data.

The ElevenLabs harness clips, `sample/` messages and `tools/results/` are not distributed.

## Notices shipped with the web bundle

The browser build ships `third-party-notices.html` next to the `.wasm`. `mise run //crates/wasm:build`
writes it to `target/wasm-pkg/` (or run `mise run //crates/wasm:notices`, which takes `--out <file>`); the
deploy must serve it and the site should link to it. Generated by `crates/wasm/notices.mjs`, it
holds:

- the data notices for `phono.bin`: the Phoible citation and CC BY 4.0 notice, and the CMUdict
  and `deunicode` license texts, read from `cmudict/LICENSE` and the crate's source;
- the license text of every Rust crate compiled into the `.wasm`, found by
  [cargo-about](https://github.com/EmbarkStudios/cargo-about) in the crate's own files. The list
  is `phono-wasm`'s dependency graph on wasm32 (`cargo tree -e no-proc-macro`). Proc-macro crates
  (`serde_derive`, `wasm-bindgen-macro`, `tsify-macros`, `syn`, …) run only at build time and are
  not shipped, so they aren't listed. Dual-licensed crates are listed under MIT.

`crates/wasm/about.toml` lists the licenses we accept for those crates: MIT, Apache-2.0, and
Unicode-3.0 for `unicode-ident` (through `wasm-bindgen-shared`). A dependency under any other
license fails `//crates/wasm:notices`, and so `//crates/wasm:build`. Check the license before adding it there.
`tsify` ships its licenses under file names cargo-about doesn't find, so `about.toml` points at
them by checksum. The generator also fails if any crate would get cargo-about's generic license
text instead of its own.

The page covers the Rust and data parts of the bundle only. npm packages bundled by the front end
need their notices added to it.
